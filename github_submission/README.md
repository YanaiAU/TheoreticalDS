# Movie Rating Prediction — Theoretical Data Science Final Project

Binary classification on real TMDB-style movie metadata: **predict whether a film is highly rated** (`Vote_Average ≥ 7.0`).

Built for a **Theoretical Data Science** course — combines practical ML with **VC dimension**, **PAC bounds**, and **generalization analysis**.

## Problem definition

| | |
|---|---|
| **Input** | Movie metadata (`popularity`, `vote count`, `year`, `genre`, `language`) + text (`title`, `overview`) |
| **Output** | `High_Rated ∈ {0, 1}` where 1 ⇔ `Vote_Average ≥ 7.0` |
| **Split** | 80/20 stratified train/test; balanced undersampling on train for metadata models |
| **Metrics** | Accuracy, balanced accuracy, F1, ROC-AUC, PR-AUC (imbalance-aware) |

## Why feature dimension d = 23?

The metadata feature vector has **23 dimensions**, so linear classifiers have **VC dimension = d + 1 = 24**.

| # | Feature group | Count | Details |
|---|---------------|------:|---------|
| 1 | Numeric | **3** | `log_popularity`, `log_vote_count`, `Release_Year` |
| 2 | Genre flags | **12** | One-hot for the 12 most frequent genres |
| 3 | Language flags | **8** | One-hot for the 8 most frequent languages |
| | **Total d** | **23** | |

This is defined in the notebook (`TOP_GENRES = 12`, `TOP_LANGS = 8`):

```python
feature_cols = [
    "log_popularity", "log_vote_count", "Release_Year",
    *genre_columns,   # 12 columns
    *language_columns # 8 columns
]
# len(feature_cols) == 23
```

**Why not more?** We deliberately cap genre/language indicators to keep the feature space small and interpretable — and to keep VC dimension tied to a clear formula for the theory section.

**MiniLM model:** uses 384-d sentence embeddings + linear head → VC dim = **385** (separate from metadata d = 23).

**Training set:** n ≈ 7,860 → ratio **n / VC ≈ 328** (PAC learning wants n ≫ VC ✓).

## Models

| # | Model | Type | Course connection |
|---|-------|------|-------------------|
| 0 | Uniform random | Baseline | Chance performance |
| 0 | Majority class | Baseline | Imbalance trap (high acc, zero F1) |
| 1 | Logistic Regression | Metadata | Linear predictor, L2 regularization |
| 2 | CatBoost | Metadata | Boosting, high capacity |
| 3 | TF-IDF + LogReg | Text | Sparse linear text classifier |
| 4 | TF-IDF + Random Forest | Text | Nonlinear ensemble on text |
| 5 | LSTM | Text | Neural sequence model (from scratch) |
| 6 | MiniLM + LogReg | Language | Pretrained semantic embeddings |

---

## Results (summary)

Best model: **CatBoost (metadata)** — ~**79%** accuracy, ~**0.87** ROC-AUC.

| Insight | Finding |
|---------|---------|
| Metadata vs text | Structured features beat plot summaries |
| LSTM vs MiniLM | Pretrained language understanding >> training from scratch |
| Theory | Low VC (LogReg) → tighter generalization; CatBoost higher capacity |

Full table and plots: run the notebook or see [`SUMMARY_REPORT.md`](SUMMARY_REPORT.md).

## Dataset

**File:** `mymoviedb.csv` (~9,837 rows)

Real TMDB-style export: titles, overviews, popularity, vote counts, genres, languages, poster URLs. Not synthetic — includes real films (e.g. *Spider-Man: No Way Home*, *The Batman*) with authentic `image.tmdb.org` poster links.

Columns: `Release_Date`, `Title`, `Overview`, `Popularity`, `Vote_Count`, `Vote_Average`, `Original_Language`, `Genre`, `Poster_Url`.
